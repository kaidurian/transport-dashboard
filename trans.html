🚂 Generate Trailer

Define one or more trailer trains. Axle #1 of each train sits at the entered X offset — the distance from the barge's origin (0,0) to the top-left corner of the trailer; every following axle = previous axle's X − line spacing, all sharing the same Y offset — the distance from origin (0,0) to the top-left corner of the trailer along Y — and VCG. X offset and Y offset are kept in sync with Excel sheet "Input", cells B5 (X offset) and B6 (Y offset): editing either field here writes it straight to Excel, and the ⇩ button next to each label pulls the latest value back in. New trains start with the same line spacing and X/Y offset as the trailer above them. Split each train's axle-line range into axle groups (e.g. axle lines 1–5 @ 25 t, axle lines 6–10 @ 50 t) and pick one of the 4 fixed groups for each range from the dropdown — or mark a group No line load for axles that carry no cargo weight. For a Goldhofer or SPMT preset trailer, each axle line is really a pair of physical axles (a right axle and a left axle sitting opposite each other) — use each group's Axle row field to apply that group to both axles, the right axle only, or the left axle only, so e.g. a 6-line/12-axle Goldhofer can have columns 1–2 in one group (both rows) while columns 3–6's right axles sit in a second group and their left axles sit in a third. If a train is actually made up of several separate physical SPMT units (e.g. a 10-line train built from a 4-line unit followed by a 6-line unit), use that train's AutoCAD split field to enter the axle-line count per unit, front → back (e.g. 4,6) — each unit then gets its own AutoCAD block insert on export, instead of one block for the whole train; leave it blank for the old one-block-per-train behavior. Rows are written to Load_Editor!B (name, e.g. Group_1_line_1) and D:G starting at row 124 (D = Line load t, E = X, F = Y, G = VCG). Use "Load from Excel" to pull an already-generated trailer back in for editing.
